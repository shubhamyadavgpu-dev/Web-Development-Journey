# 🔌 REST APIs

REST APIs allow different parts of an application to communicate.

## HTTP Methods

| Method   | Purpose       |
| -------- | ------------- |
| `GET`    | Retrieve data |
| `POST`   | Create data   |
| `PUT`    | Replace data  |
| `PATCH`  | Update data   |
| `DELETE` | Delete data   |

## Example

```text
GET     /api/users
POST    /api/users
GET     /api/users/:id
PATCH   /api/users/:id
DELETE  /api/users/:id
```

# 🗃️ SQL vs NoSQL


# ⚙️ Environment Variables

Sensitive configuration should not be hard-coded.

Example:

```text

JWT_SECRET=your_secret
PORT=5000
API_KEY=your_api_key
```

Use environment variables for configuration and secrets.

```text
        ↓
3️⃣ Design the solution
        ↓

        ↓
```

# 🐛 Debugging Philosophy

Bugs are part of development.

Instead of immediately searching for the complete solution:

```text
❌ Error
   ↓
🤔 Understand the error
   ↓
🔍 Find the problematic section
   ↓
🧪 Test assumptions
   ↓
🛠️ Fix
   ↓
✅ Verify
```

The goal is to become comfortable with debugging rather than avoiding errors.
